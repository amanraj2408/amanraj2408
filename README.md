## About Me

I'm a **Full Stack Developer** building modern web applications end to end — from responsive React/Next.js interfaces to Node.js, Spring Boot and FastAPI backends — with a strong interest in **AI-powered and real-time systems**.

- **Frontend:** React.js, Next.js, TypeScript, Tailwind CSS, Material UI, shadcn/ui
- **Backend:** Node.js, Express.js, Java / Spring Boot, Python / FastAPI, REST APIs
- **Real-time:** WebSockets and MQTT for live telemetry and monitoring dashboards
- **AI / ML:** Computer vision with YOLOv8, OpenCV and PyTorch for video analytics
- **Cloud & DevOps:** AWS (S3), Docker, Kubernetes, Jenkins, GitHub Actions, CI/CD
